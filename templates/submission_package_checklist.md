# Submission Package Checklist

Gate status: draft

## Manuscript and Metadata

- [ ] Title, abstract, keywords, author information, and affiliations are confirmed.
- [ ] Manuscript sections match the target article type and current official instructions.
- [ ] Funding, conflicts, author contributions, acknowledgements, and AI-use disclosure are resolved where required.
- [ ] Ethics, consent, registration, and reporting-guideline fields are verified where applicable.

## Evidence and Assets

- [ ] Strong claims pass the claim-to-evidence gate.
- [ ] Figures, tables, captions, units, and in-text references are consistent.
- [ ] Source data and supplementary files are mapped to manuscript claims.
- [ ] References are verified, deduplicated, and consistent with in-text citations.
- [ ] Data, code, protocol, model, and preregistration availability statements match actual access routes.

## Package QA

- [ ] Required file names, formats, sizes, resolution, and anonymization are checked.
- [ ] Cover letter and response documents do not contradict the manuscript.
- [ ] Rendered PDF or portal preview has been inspected.
- [ ] Unresolved fields and human decisions are listed explicitly.
